#Noise suppression for the audio the wake word is looked for in, behind
#assistant.wake.wake_noise_suppression. Aimed at a fan or an air conditioner:
#the steady sort that never stops and sits under everything said in the room.
#
#**Linux only, and only where a wheel exists.** The project publishes
#manylinux x86_64 and aarch64 wheels for CPython up to 3.12, and nothing
#else - no Windows, no macOS, and no source distribution to fall back on. Off
#a marker, pip finds no candidate at all on those platforms and fails the
#WHOLE file, which is a panel that cannot install because of an optional
#audio filter.
#
#Where it is skipped the wake word starts without it and the log names what
#was dropped - see WakeSpotter._attempt(). It is an improvement to the
#spotter, never a condition of it running.

# ── Local text to speech ──────────────────────────────────────────────────────
# Kyutai Pocket TTS. 100M parameters, CPU only - Kyutai report no speedup from
# a GPU, so the plain torch wheel is correct and there is nothing to configure.
# Needs no API key and no network once the weights are cached.
#
# Required: it is the default voice backend. ElevenLabs stays as a fallback and
# needs a key, so a panel with neither has no spoken replies.
#
# It pulls torch and torchao, which is a large download - several hundred MB on
# a machine that has neither. The CPU wheel is what is wanted; installing the
# CUDA one wastes gigabytes for no gain here.
pocket-tts

# ── Bluetooth ─────────────────────────────────────────────────────────────────
