# Nighttime Clock

Turns the panel into a clock for a dark room, and the brightness down to go
with it.

As night approaches the screen fades gradually rather than changing all at
once. At the night time it switches to a near-black page showing the time, the
date and the temperature, with a few slow points of light drifting across it.

Touch it during the night and it comes half-way up so you can read it. Leave it
alone and it settles back down within a few seconds. At the day time it returns
to full brightness and to whatever page it was on before.

Everything is in **Settings → Nighttime Clock**: the two times, whether to fade
at all, how long the fade takes, both brightness levels, how quickly it settles,
and the fireflies.
